# DEAD AIR // BLACKPINE BROADCAST (BUREAU–9)

> **Атмосферний ретро-хорор від першої особи для 1–4 гравців у сетингу середини 1990-х років.**  
> Спеціальна оперативна група міжнародного бюро розслідувань **«BUREAU–9»** прибуває на занедбаний ретранслятор **«Blackpine Broadcast / Station 04»** за таємничим сигналом біди.

---

## ◫ Сюжет та Операція 004

О **02:17** 23 жовтня 1996 року законсервована телестанція Blackpine Broadcast раптово відновила трансляцію на частоті 96.4 МГц. В ефірі чути голос чергової зміни, проте приміщення станції порожні. Старший звукоінженер **Артур Коул** (Артем Коваль) залишив три майстер-касети з фіксацією аномалії перед тим, як зміну поглинула сутність **«Диктор»** (*The Anchor*).

Четверо оперативників **BUREAU–9** прибувають на службовому фургоні у внутрішній двір станції. Їхнє завдання:
1. Проникнути до станції крізь технічний вхід.
2. Знайти **3 майстер-касети** Артура Коула (Архів, Студія 04, Техсклад).
3. Знайти **2 промислових керамічних запобіжники на 380V** (Вентвузол та Серверна).
4. Вставити запобіжники в електрощит генераторної та підняти рубильник.
5. В апаратній кімнаті передати касету на супутники BUREAU–9 через головний пульт.
6. В умовах червоної тривоги та люті Кривавого Диктора добігти коридором до подвір'я та евакуюватися у фургон!

## ▷ Швидкий запуск

Потрібні **Node.js 20+** (або 22+) та сучасний браузер із WebGL (Chrome, Edge, Firefox).

```bash
# Встановлення залежностей
npm install

# Запуск сервера розробки (клієнт Vite + Socket.IO сервер на порту 3000)
npm run dev
```

Відкрийте у браузері:
* **Гра:** [http://localhost:3000](http://localhost:3000)
* **3D-Архів моделей (14 об'єктів):** [http://localhost:3000/models-preview.html](http://localhost:3000/models-preview.html)
* **Білдер локацій та розстановки предметів:** [http://localhost:3000/builder.html](http://localhost:3000/builder.html)

Збирання релізу:
```bash
npm run build
npm start
```

Запуск автоматичних тестів:
```bash
npm test
```

## 👥 Кооператив (1–4 гравці)

1. **Хост**: Відкрийте гру, оберіть персонажа, натисніть **«Грати разом» → «Створити кімнату»**. Отримайте 5-значний код кімнати.
2. **Гості**: Відкрийте ту саму адресу (або IP-адресу хоста у локальній мережі / Radmin VPN, наприклад `http://192.168.1.50:3000`), введіть код і натисніть **«Приєднатися»**.
3. Усі підключені гравці стоять у реальному 3D-дворі біля фургона зі своїми іменами та класами над головою.
4. Хост натискає **«Почати запис»** — стартує вступне прибуття фургона та дослідження станції.

## 🏢 Структура комплексу Blackpine Broadcast

- **Внутрішній двір (Courtyard):** Майданчик евакуації, фургон AX 0417 TB, трансформаторний сарай 380V, антена з червоним маяком, паркан.
- **Головний коридор:** 60-метрова центральна вісь з облупленою штукатуркою, трубами, ліхтарями та гермодверима.
- **Сектор 01 (Архів):** Стелажі VHS-плівок 1986–1996, перша майстер-касета.
- **Сектор 02 (Апаратна):** Стіна CRT-моніторів та головний пульт супутникового аплінку BUREAU–9.
- **Сектор 03 (Генераторна):** Високовольтний щит 380V, рубильник живлення та вентиляційні контури.
- **Сектор 04 (Студія 04):** Дикторський стіл новин, софіти, штативні камери ТК–04, друга майстер-касета.
- **Сектор 05 (Вентвузол):** Вентиляційні шахти та перший керамічний запобіжник 380V.
- **Сектор 06 (Серверна):** Обчислювальні стійки телерадіомовлення та другий керамічний запобіжник.
- **Сектор 07 (Техсклад):** Ящики, бочки та третя майстер-касета Артура Коула.
- **Сектор 08 (Диспетчерська):** Пост радіозв'язку та моніторингу ретрансляційної вежі.
- **Обхідні тунелі (Петлі):** Бічні коридори між секторами для маневрування та втечі від Диктора.

## 🛠 Технологічний стек

* **Frontend:** Three.js, WebGL Post-Processing (CRT scanlines, grain, chromatic aberration, danger vignette), Web Audio API (просторовий 3D звук).
* **Backend:** Node.js, Express, Socket.IO (авторитетна синхронізація кімнат, фізики, цілей, штучного інтелекту монстра).
* **Tooling:** Vite, Node Test Runner, procedural canvas texturing.
