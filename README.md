# Dead Air: Blackpine Broadcast — Unity 6

Ігровий проєкт для **Unity 6 (6000.6.3f1)** з підтримкою **Unity Editor Pipeline** та системи інвентарю. Відкрийте цю папку в Unity Hub через **Add → Add project from disk** і запустіть сцену `Assets/Scenes/Blackpine.unity` кнопкою **Play**.

*Розпакуйте zip-архів і запустіть `DeadAir.exe`.*

## Що перенесено та покращено

- 3D локація Blackpine: подвір’я, станція, 8 секторів, двері, освітлення, 367 об’єктів із кастомної мапи.
- Оптимізація графіки: GPU Instancing для матеріалів станції та Runtime Static Batching для низького навантаження на GPU.
- Повноцінна система інвентарю: вибір 5 слотів, викидання на підлогу ліхтарика та будь-яких предметів, персональні картки доступу для кожного гравця окремо.
- Підтримка Unity Editor Pipeline (com.unity.pipeline 0.8.0-exp.1) для прямого зв'язку з AI-асистентами через MCP.
- Одиночний режим, режим дослідження й LAN кооператив до 4 гравців без Node.js сервера.
- Класи Victor, Vivian, Edgar, Hazel; предмети, схованки, підняття напарника, витривалість, розсудок, рація, переслідування й оглушення Диктора.
- Повний цикл завдання: 3 касети → 2 запобіжники → живлення → частота 96.4 МГц → передача → евакуація.
- Головне меню з вибором персонажа, лобі, HUD, карта, калібрування, пауза, досьє, завершення та меню рації. Налаштування гучності ефектів і оточення, миші та VHS зберігаються між запусками.
- Процедурні звуки вебверсії: кроки, двері, предмети, рація, обладнання, дихання, серцебиття, Диктор і фонові шуми; просторове звучання та обмеження піків гучності.

## Кооператив у локальній мережі

1. Хост натискає **Створити кооп сеанс**. У лобі видно код кімнати.
2. Інші гравці вводять IP адресу комп’ютера хоста та код, потім натискають **Приєднатися**.
3. Хост відкриває TCP порт **32004** у локальній мережі та натискає **Почати запис**.

Підключення працює в LAN або через VPN, що надає пряме з’єднання між комп’ютерами. Для гри через інтернет без VPN потрібне переспрямування порту на маршрутизаторі.

## Інструменти редактора

Меню **Dead Air** у Unity містить **Import Complete Web Scene**, **Validate Migration**, **Validate LAN**, **Create Playable Scene** і **Build Windows**. Візуальна мапа зберігається у `Assets/Resources/World/station.prefab` та `exterior.prefab`. Старий Map Builder редагує тільки дані: для зміни геометрії використовуйте вихідний вебредактор і повторний експорт нижче.

Якщо ви змінюєте вихідну JS мапу або моделі, з кореня репозиторію запустіть:

```powershell
node scripts/export-unity-data.mjs
node scripts/export-unity-scene.mjs
```

Другий скрипт запускає локальний Vite та Chrome через Playwright, малює справжні Canvas текстури й записує `Assets/SourceExport`. За потреби задайте `CODEX_NODE_MODULES` шляхом до папки пакетів Node, де встановлено Playwright. Далі виконайте **Dead Air → Import Complete Web Scene** у Unity. OBJ експортер не переносить текстури й не використовується для поточної мапи.

Вебверсія лишилася у корені репозиторію для порівняння. Unity гра запускається автономно. Усі дані правил використовують вихідні координати; імпортер віддзеркалює X для системи координат Unity, і гравець перетворює координати на межі мережевих повідомлень.
