# Процедурна музика та звуки

`DeadAirAudio.cs` і `DeadAirAudio.Synthesis.cs` генерують бібліотеку з 60 кліпів під час запуску: 4 стереотеми по 32 секунди, 7 фонових петель і 49 ефектів. Частота синтезу — 32 кГц. Бібліотека не потребує зовнішніх аудіофайлів.

| Події | Звучання |
| --- | --- |
| Меню та лобі | Розстроєні дзвони/фортепіано та низький гул |
| Дослідження | Повільна музична підкладка порожньої станції |
| Загроза й низький розсудок | Дисонансні тремоло, серцебиття, шепіт і шум у вухах |
| Погоня | Ритмічна низька перкусія; плавне посилення без перезапуску фрази |
| Кроки | Окремі кроки й біг на плитці, гравії дворів і металевих сходах |
| Предмети | Ліхтар, VHS-камера, карта, касети, запобіжники, перепустки, каністра, взяття/викидання |
| Обладнання | Двері, шафи, генератор, лампи, вентиль, калібрування, передавач, рація й тривога |
| Персонажі | Сигарета/запальничка, ключ, диктофон, компас, поранення й підняття товариша |
| Диктор | Присутність, підглядання, зникнення, оглушення, поява обличчя |
| Скример павука | Удар, низький спадний тон, дисонансний крик і швидкий шурхіт лап |

Усі чотири музичні петлі стартують на спільному DSP-годиннику. Їхні рівні змінюються за фазою гри, близькістю монстра й розсудком. На час різкого скримера музика й фонові шуми приглушуються. Закінчення нот переходять через межу петлі.

`DeadAirAtmosphere` відстежує підтверджені ігрові зміни й запускає звуки у відповідних місцях. Звуки дверей, механізмів та інших гравців просторові; власні предмети, інтерфейс і скримери звучать без ослаблення від відстані. Особистий звук зупиняється при скасуванні дії. Кнопки гучності керують загальним рівнем, музикою/фоном та ефектами; вимкнення звуку одразу прибирає всі джерела.

`ValidateInstruments()` перевіряє, що всі семпли скінченні, непорожні й не перевищують допустимий пік. `ExportLibrary(folder)` зберігає всю бібліотеку як PCM16 WAV із позначками петель. Перевірка `DeadAirPresentationValidation.ValidateAndBuild()` експортує файли до `Verification-Presentation/Audio`, перевіряє геометрію/екран/скримери й створює Windows-збірку.

Для перевірки реального ігрового рендерингу запустіть Windows-гру з параметром `-deadAirHorrorCapture <абсолютна папка>`. Кадри та `horror-runtime-report.txt` включають парковку, об’ємну павутину, повноекранні скримери, приховування/відновлення інтерфейсу та мережеву подію павука.
